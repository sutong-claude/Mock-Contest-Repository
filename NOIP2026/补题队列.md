## 每条任务的统一验收模板

```
[证据] 来源：官方 record / 保存快照 SHA / 录音时间 / 转写页码 / 本地脚本输出
[动作] 用户原思路 → 假说 → 最小反例 [X] → 最小 diff → 是否实际提交
[状态] IDEA/PROVED/CODED/VERIFIED/FROZEN/SUBMITTED/SCORED
[验证] 命令 + 种子 + 组数 + 真值来源 + 限制（LOCAL-VERIFIED ≠ OJ-AC）
[同步] 账本 JSON → build_repo_state.py → verify_repo.py → commit SHA + 回读
[剩余] 明确写出还不知道什么
```
