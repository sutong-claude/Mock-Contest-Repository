## T1 `window`｜非负短区间计数（100 分）

### 题面

给定长度为 $n$ 的整数序列 $a_1,\dots,a_n$ 与正整数 $K$。称区间 $[l,r]$（$1\le l\le r\le n$）**合法**，当且仅当

- 长度不超过 $K$，即 $r-l+1\le K$；
- 区间和非负，即 $\sum_{i=l}^{r} a_i \ge 0$。

求合法区间个数。

### 输入格式

第一行一个正整数 $T$。接下来 $T$ 组数据，每组两行：第一行 $n\ K$；第二行 $n$ 个整数 $a_i$。

### 输出格式

$T$ 行，每行一个整数，表示答案。保证答案不超过 $2^{63}-1$。

### 数据范围

| 子任务 | 分值 | 约束 |
| --- | ---: | --- |
| 1 | 20 | $n\le 50$，$\lvert a_i\rvert \le 10$ |
| 2 | 20 | $\sum n\le 2000$ |
| 3 | 20 | $a_i\ge 0$ |
| 4 | 40 | 无额外约束 |

全部数据：$1\le T\le 5$，$1\le K\le n\le 2\times 10^5$，$\sum n\le 2\times 10^5$，$\lvert a_i\rvert \le 10^9$。

### 样例

输入
```
2
5 3
1 -2 3 -1 2
4 2
-1 -1 -1 -1
```
输出
```
9
0
```

样例解释：第一组共 12 个长度 $\le 3$ 的区间，其中 $[1,2],[2,3],[2,4]$ 和为负，其余 9 个合法；第二组所有非空区间和为负，答案 0。

### 命题陷阱

- **值域**：$a_i$ 到 $10^9$，前缀和与计数必须用 64 位；`int` 溢出是最常见的考场失分点。
- **长度上限**：`r-l+1<=K` 是滑窗的「左端点下界」而不是「窗口内元素个数上界」的简单滑动；把 $K$ 当成值域上界会全错。
- **$\le 0$ / $\ge 0$ 边界**：前缀和相等必须计入（$\ge$），用 `lower_bound` 而非 `upper_bound` 处理查询会漏掉一类解。
- **多测**：必须完整清理上组数据；呼应 `NOIP2026/考场执行卡_NOIP.md` 的「全局容器 `.clear()`」跨界死穴与 `错因总表.csv` #10。

## T2 `lamps`｜定长翻转（100 分）

### 题面

有 $n$ 盏灯排成一列，第 $i$ 盏状态为 $s_i\in\{0,1\}$。一次操作可以选择一个起点 $i$（$1\le i\le n-L+1$），把第 $i$ 到第 $i+L-1$ 盏灯**全部取反**（$0\leftrightarrow 1$）。求把所有灯熄灭（全 0）所需的最少操作数；若不可能，输出 `-1`。

注意：同一个起点可以操作多次，但显然没有必要；操作顺序不影响结果。

### 输入格式

一行两个正整数 $n\ L$，第二行一个长度为 $n$ 的 `01` 串。

### 输出格式

一行一个整数：最少操作数，或 `-1`。

### 数据范围

| 子任务 | 分值 | 约束 |
| --- | ---: | --- |
| 1 | 20 | $n\le 12$ |
| 2 | 20 | $L=1$ |
| 3 | 20 | 保证有解 |
| 4 | 40 | 无额外约束 |

全部数据：$1\le L\le n\le 10^6$。

### 样例

输入 1
```
5 3
10110
```
输出 1
```
-1
```

输入 2
```
6 3
101101
```
输出 2
```
4
```

样例 1 解释：$n=5,L=3$，只能从起点 1、2、3 翻转。把三种翻转次数记为 $x_1,x_2,x_3\in\{0,1\}$，逐位列方程可验证无解（详见 `solution.md`）。

### 命题陷阱

- **有解性不是自动的**：$L>1$ 时并非所有初态可达全 0，必须判定 `-1`；这是与经典「前缀翻转」最大的区别。
- **贪心的正确性依赖「最左灯只能被一个起点改变」**：必须给出交换论证，不能只凭直觉。
- **差分数组下标**：差分要开到 $n+L+1$，写到 $i+L$ 时越界是常见错误。
- **不要 BFS**：$n=10^6$，状态空间 $2^n$ 只适用于子任务 1 的对拍。

## T3 `segments`｜双约束最大覆盖（100 分）

### 题面

给定两个长度为 $n$ 的整数序列 $a,b$。称区间 $[l,r]$ **好**，当且仅当

$$\sum_{i=l}^{r} a_i \ge 0 \quad\text{且}\quad \sum_{i=l}^{r} b_i \ge 0 .$$

在数轴 $1..n$ 上选出若干个**两两不相交**的好区间，最大化这些区间的**长度之和**（未被覆盖的位置允许存在）。输出这个最大值。

### 输入格式

第一行 $n$；第二行 $a_1..a_n$；第三行 $b_1..b_n$。

### 输出格式

一行一个整数：最大长度和。

### 数据范围

| 子任务 | 分值 | 约束 |
| --- | ---: | --- |
| 1 | 15 | $n\le 8$ |
| 2 | 25 | $n\le 2000$，$a_i,b_i\in\{-1,0,1\}$ |
| 3 | 20 | $a_i=b_i$ |
| 4 | 40 | 无额外约束 |

全部数据：$1\le n\le 2\times 10^5$，$\lvert a_i\rvert,\lvert b_i\rvert \le 10^9$。

### 样例

输入
```
6
1 -5 2 -3 4 -2
1 -5 2 -3 4 -2
```
输出
```
5
```

### 命题陷阱（本题是全场核心）

- **必须允许「跳过一个位置」**：没有 `dp[i]=dp[i-1]` 的继承，样例和大量数据会偏小。仓库 11-03 转写 PDF 里 `[G]` 提到的「`maxcover` 缺 `f[i]=f[i-1]`」在本轮被独立复算确认（最小反例 `n=4, a=[-2,1,1,-1], b=[0,-1,1,-1]`，真值 3、缺继承版 2）。
- **不等号必须非严格**：支配条件 $S_a[t]\le S_a[i]$、$S_b[t]\le S_b[i]$ 取等号时合法；写成 `<` 会让 $n=1,a=b=[0]$ 从 1 变 0。
- **前缀和到 $10^9\times n\approx 2\times10^{14}$**：必须 64 位；坐标压缩的对象是前缀和而不是原数组。
- **二维支配**：一维最大子段和的做法（单个变量记录历史最小前缀）在这里不成立，因为约束是二维偏序。这直接对应仓库 `错因总表` #16「正确朴素模型没有触发复杂度转换」。

## T4 `pairs`｜部分错排计数（100 分）

### 题面

令 $N=n+m$。求满足下列条件的排列 $\pi\in S_N$ 的个数，对 $P=1\,000\,000\,007$ 取模：

$$\pi(i)\ne i \quad \text{对所有 } 1\le i\le n .$$

也就是说，只有前 $n$ 个位置被禁止放自己，其余 $m$ 个位置不限制。等价于：求 $N\times N$ 的 0-1 矩阵中「每行每列恰一个 1，且前 $n$ 行的主对角线元素必须为 0」的方案数（即该 0-1 矩阵的 permanent）。

### 输入格式

一行两个非负整数 $n\ m$。

### 输出格式

一行一个整数：答案 $\bmod P$。

### 数据范围

| 子任务 | 分值 | 约束 |
| --- | ---: | --- |
| 1 | 15 | $N\le 8$ |
| 2 | 25 | $N\le 20$ |
| 3 | 20 | $m=0$（完全错排） |
| 4 | 40 | 无额外约束 |

全部数据：$0\le n,m$，$n+m\le 10^6$，且 $n+m < P$。

### 样例

输入 1
```
2 1
```
输出 1
```
3
```

输入 2
```
1 0
```
输出 2
```
0
```

输入 3
```
0 3
```
输出 3
```
6
```

输入 4
```
3 3
```
输出 4
```
426
```

### 命题陷阱

- **$m=0$ 时答案是错排数** $D_N$，不是 $(N-1)!$；$n=0$ 时答案是 $N!$。两个端点必须手算验证。
- **$n>m$ 不能套用「所有位置都禁」的公式**：容斥只对被禁的 $n$ 个位置做，$\binom nk$ 而不是 $\binom Nk$。
- **复杂度**：$N\le 10^6$，逐项 `qpow` 求逆元是 $O(N\log P)$，会超时；必须用线性递推逆元或组合数递推。仓库 Day8 A 赛时源码正是「循环内 `qpow`」致 TLE 的 `[E]` 案例，赛后正解已改成一次 `qpow` + 线性逆元。
- **$N\ge P$ 时线性逆元失效**：题面已用 $N<P$ 规避；这是刻意的边界，考场上要能说出为什么。
