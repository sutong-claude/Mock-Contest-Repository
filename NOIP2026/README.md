## 完成定义（不要只写计划）

- 每一条补题任务必须落到：`CODED`（源码文件）→ `VERIFIED`（独立 oracle / 官方样例 / 对拍记录）→ `FROZEN`（可回滚副本）→ 若参赛则 `SUBMITTED`（真实 OJ record）→ `SCORED`（逐点分）。
- 本地对拍全绿只能写 `LOCAL-VERIFIED`，**不能写 OJ-AC**。
- 估分、目标分、反事实「本来能拿 X 分」一律标 `[G]` 或 `[H]`，不得混进账本分数列。
