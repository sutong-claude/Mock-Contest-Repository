- 当前阶段：CSP-S 2026 已考完（初评未发布），转向 **NOIP 2026 备战**。

## 4. 方法论（仓库最值钱的资产）

1. **十级证据标签** `[OJ]/[F]/[R]/[V]/[U]/[G]/[P]/[E]/[H]/[X]`；`[G]` 必须回 OJ/源码才能升级。
2. **得分资产状态机** `IDEA → PROVED → CODED → VERIFIED → FROZEN → SUBMITTED → SCORED`；`PROVED` 仍不是稳定分；「赛时想到了」不算分。
3. **复盘九大块**（`模拟赛复盘总协议_v2.md`）：证据完整性 → 比赛画像 → 能力定位 → 逐题复盘 → 争议深挖 → 排名/机会成本 → 时间线止损 → Skill 沉淀 → 行动清单。
4. **赛中研究协议**：结论带标签、猜想写证伪程序、两次推翻后禁止纯手玩、checker 四格契约、75 分钟硬切、最小反例与大样例分工、`OJ 结果不是证明等级`。
5. **赛前执行卡**：四个「换」、每题六步、4 小时检查点、交卷前清单、**部分分必须冻结**、**唯一提交源**、**oracle 也要过 checklist**、前 90 分钟扫四题、最后 10 分钟禁写新算法。
6. **三层数学契约**（Day6/7 后）：对象 → 充要性 → 实现契约，代码前写三行。
7. **验证纪律**：坏 oracle 跑五万组也没有证明力；仓库三次被坑（Day2 A 空 `gen` 却称 1000 组全对、Day3 B checker 不验 NO、Day4 B brute 漏端点条件）。
8. **覆盖矩阵**：每场应有 README / 复盘 / 题解 / 逐段复现 / 源码逐段解剖 / 键盘分析 / 验证报告 / 资料完整性报告。
9. **大样例 15 分钟 SOP `[G]`**：`-Wall -Wextra -fsanitize=address,undefined` → `diff -w` → 缩阈迫爆 → 多测 `.clear()` → 极小 `n≤5` 反例；绝不死磕。
10. **隐私**：不上传原始录屏/按键/剪贴板/完整聊天/账号页/未脱敏源码历史/OCR 原文与图片鉴权 URL。`.gitignore` 已列黑名单。
