## 1. 考古结论（都是可复算的 `[E]`）

### 1.1 Day1 A 的四版链不是「调符号调错」，是「模型不成立」

编译 `2026-09-25_CSP-S模拟赛day1/赛时代码/A_v1..v4_*.cpp` 与改写版，对 $n=1..7$ 全部 5,913 个排列对拍（真值取已独立验证过的改写版）：

| n | 全排列 | v1 错 | v2 错 | v3 错 | v4 错 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 2 | 0 | 0 | 0 | 0 |
| 3 | 6 | 3 | **1** | **1** | 0 |
| 4 | 24 | 18 | **7** | **7** | 0 |
| 5 | 120 | 98 | 53 | 53 | 0 |
| 6 | 720 | 642 | **378** | **378** | 0 |
| 7 | 5040 | 4564 | 3079 | 3079 | 0 |
| **n=2..7 合计** | **5,912** | **5,325** | **3,518** | **3,518** | **0** |

- 历史文档 `逐段考古纪要.md` 的 **3,518/5,912**、`复盘报告.md` 的 **n=3 错 1/6、n=4 错 7/24、n=6 错 378/720**，以及「v4 在 5,912 例上 0 mismatch」**全部独立复算吻合** → 从 `[R]` 升级为 `[E]`。
- 最小反例 `[3,1,2]`：真值 3，v1/v2/v3 都输出 2，v4 输出 3；`[2,1,3,4]`：真值 5，前三版输出 6（**超过 $C(4,2)=6$ 的理论上界**，正是复盘里 T+0:58「怎么出现 20 了」的结构性信号）。
- **v2 与 v3 去掉注释后逻辑逐字相同**：20:48 那个「最终版」只删了调试输出，没有改模型。
- v1 在 779 例上输出**超过理论上限**，其中高估 3,220 例、低估 2,105 例 → 双向都错，证明不是「正负号写反」能解释的。
- 根因（与 `题解.md` 一致）：前缀逆序对数 $L[r]-L[l-1]$ 会把一端在 $[1,l-1]$、一端在 $[l,r]$ 的**跨界点对**算进区间逆序对。逆序对是点对，不是元素自身贡献量，不能前缀相减。
- 21:10 的 v4 换成「固定左端点、逐右端点显式维护 $x/y$」的正确模型，代价是 `std::distance` 在 `multiset` 双向迭代器上 $O(n)$，整体 $O(n^3)$ → 这才有上轮的树状数组改写。**历史不能缩成「前缀公式错了」；准确链条见 `01`。**

### 1.2 「520 vs 522」定位到 2 个录制脚本事件

`690 保存事件` 表里有 522 条 `is_source && has_nonempty_content` 事件，而 `520份赛时C++非空源码快照.jsonl` 只有 520 行。逐 `(path, sha256, bytes)` 对齐后：

```
522 = 516 .cpp + 4 .cc + 2 .py
520 = 516 .cpp + 4 .cc
差 2 = contest_replay_capture.py（42,371 B, sha16 7cdacb9042e6，同一内容两种路径拼写）
```

即 **520 是「C++ 源码快照」语料，522 是「被分类为源码的事件」**，两者定义不同，不是数据丢失。这条也顺带解释了 `codelands-Day2` 版次索引为什么是 76 行而不是 78。

### 1.3 CodeLands2 悬案：把边界钉死，不假装定案

从 690 事件表复算 `20261013_141730` 单场：**126 个事件、78 条源码非空、36 次 0 字节、相对时间 2803.190–14969.239 s（约 3h23m）**。在 `14969.239014` 这一个时间戳上有 **22 个事件**，其中 **8 个是 243 B 的空模板**（同一 SHA `c5cf23d14a3d1c9d…`）→ 印证「批量复制不是 8 次独立研究」。

四份命名源码的字节数与 SHA 前缀在 **520 JSONL 与 2581 文件 SHA 目录之间双向互证全部一致**：

| 文件 | 字节 | sha16 |
| --- | ---: | --- |
| `zerofree.cpp` | 1580 | `46cdf6edd73148aa` |
| `count.cpp` | 1732 | `624d1556949cd4` |
| `color.cpp` | 1385 | `18950accf6f464f7` |
| `silent.cpp` | 273 | `6557a1184d1cdc43` |

**但 40/61 仍为 `CONFLICT`**：仓库没有任何官方逐提交 record；`.in/.ans` 只进了 SHA 目录、正文不在 Git，因此考古文档里的 **5/8、4/8 附件通过率本轮无法重跑**，保持 `[R]`。能升级的只有「源码存在 + 哈希 + 静态结构」这一层。详见 `02`。
