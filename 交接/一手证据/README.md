## 阅读事件切忌三件事

1. **不要简单取最后一个 SAVE 为交卷源码**。CodeLands2尾声有243字节模板、零字节清理、目录复制。某版本的来源字段只有磁盘保存的时间和SHA，OJ提交需额外从平台记录确认。
2. **不要把Gemini算作原始证据**。仓库《双Gemini结论与事实分栏》标出 Day4 B 错oracle与“5万组”矛盾；Day9 A 后验一行修复仍非OJ100。
3. **不要“看完SHA就叫逐帧理解”**。本轮发现240段MKV，仅全面索引，没有每帧录像逐帧观摩。本轮用户包含更完整的私有下载索引，公共GitHub不包含敏感录像或源键盘日志。
