## 1. 考前 4 个靶向专题「一学就能换回 50~100 分」`[G]`

| 靶向 | 内容 | 对应仓库真题 | 3 分钟硬指标验收 |
| --- | --- | --- | --- |
| 1 线性逆元 5 行板子 | `d[n]=qpow(fac[n],P-2); for(i=n-1..0) d[i]=1LL*d[i+1]*(i+1)%P;` 组合数写成 `fac[a]*d[b]%P*d[a-b]%P`，循环内零 `qpow` | Day8 A（组合数逆阶乘性能）、CodeLands3 `alien`（90→100） | 默写并算出 `C(10,3)`、`C(10⁷,5×10⁶)` 不 TLE |
| 2 树状数组两类用法 | ① 维护前缀和（逆序对 / 前面比我小的个数）；② 维护前缀最大值优化 `O(n²)` DP（`max(f[j]-j)`） | Day1 A 记录带、Day2 C 棋子、CodeLands3 `maxcover` special | 20 行写出 `f[i]=f[i-1]` + 离散化 + BIT 前缀最大 |
| 3 折半搜索 Meet-in-the-Middle | `N≤40` 时把 `2⁴⁰` 拆成两次 `dfs` + sort/二分；多测例固定维度尾部清零、负数与 hash | CodeLands2 `color`、Day8 C 观测记录（20bit 拆 10+10） | 写出左右半枚举 + 同 key 保最大个数 + 左查负向量 |
| 4 正难则反（倒序 / 缓存） | 基环树拓扑队列倒扫求树深免建反图；删点/删边问连通块倒放成加点 + DSU；图小但 `Q` 大时缓存同起点最短路 | Day7 B 委托分组、Day9 C 虹夏、CodeLands3 `step` | 三道题各写出「倒过来做」的一句话状态转移 |

**砍课原则 `[G]`**：Y4（下）80% 生僻课（高斯消元、中国剩余定理、exKMP、三分、笛卡尔树、Treap、Splay 等）考前封存；过去十几场丢的分 90% 都在已学的 Y4（上）+ 树状数组/线段树里。

## 2. 必背 5 个极简救命板子 `[G]`

1. 离散化 + 前缀和 / 差分（区间翻转 → 差分数组 2 个单点修改，信友队 `lamps` 满分关键）。
2. 二分答案 + 单调性判定（写结构前先写一句不变量/单调性证明）。
3. 并查集（含倒序加点、带权/前驱代表两种 S 组高频变形：Day7 B、Day10 D）。
4. Dijkstra / 拓扑排序（含默认大根堆 vs `greater` 小根堆的方向检查：LGR-307 `path`）。
5. 折半枚举 / 二进制枚举三件套（`N≤20` 位掩码、`N≤10` `next_permutation`、`m^n≤10⁶` 单参数 `dfs(step)`）。

**非课程类 6 项硬核武器 `[G]`**：零失误高速枚举三件套、4 行父指针暴力求 LCA（专治考场写 SPJ Checker 或 `N≤2000` 树上题）、并查集两大变形、阶乘逆元线性倒推 + 安全取模函数、8 行快读快写、`clock()` 卡时死线（保住已拿到的最优解，绝不 TLE）。

## 3. 「小样例过、大样例挂」15 分钟必破口诀 `[G]`

**先分清三类病因**：越界/溢出与类型、多测状态残留、跨界维度错误（`n vs m`、比较器方向）。没有哪一招次次有效，按漏斗走。

| 步 | 动作 | 时间 |
| --- | --- | --- |
| 1 | 看大样例第一行是不是多组数据 `T`；15 秒核对输入格式、参数范围、行数、理论输出（样例先验尸） | 1 min |
| 2 | 大样例 RE/段错误/死循环：`return 0` 二分法定位；编译带 `-Wall -Wextra -fsanitize=address,undefined` | 3 min |
| 3 | 大样例 WA：`diff -w` 全量比对，禁止肉眼扫 11 位数（LGR-307 `func` 的 `...138` vs `...152`） | 2 min |
| 4 | 缩阈迫爆法：把 10 万行大样例缩成 5 行、数组阈值临时改小让越界先爆，配 3 行 `assert` | 3 min |
| 5 | 多测题「单挑第一组」；扫全局容器外层循环第一行 `.clear()`；扫 `n/m` 与 `priority_queue` 比较器 | 3 min |
| 6 | `n≤5` 极小反例 + F7/Watches 一击必杀（极小数字代入法，戒掉靠 F9 撞大运） | 3 min |

**10 分钟四步急救漏斗 `[G]`**：保命编译命令 → 单挑第一组 → 扫两大跨界死穴 → 缩到 `n≤4/5` 的极小反例。**绝不死磕**。

**样例文件为什么打不开 `[G]`**：单行 1000 万字符触发文本编辑器「自动换行渲染死锁」；Linux 文件管理器 `.in/.ans` 关联陷阱；极少数真坏包（CodeLands1 `tree` 样例格式事故）。解决：用 `head`/`diff`/终端，不用 GUI 渲染。

## 4. 四大无脑枚举器与「暴力自己也对不对」`[G]`

- 选/不选、删边、染色（`N≤20`）→ 二进制 `for`，连 DFS 都不写。
- 决定先后/匹配顺序（`N≤10`）→ `do-while next_permutation`。
- 每位 `1~m` 种选择（`m^n≤10⁶`）→ 单参数 `dfs(step)`。
- 0/1 可达性 → `bitset` 除以 64。
- 暴力写完 10 秒自检：拿 `n≤5` 手算或独立 oracle 对一次；**坏 oracle 跑五万组依然没有证明力**（仓库 Day3 B / Day4 B 铁律）。

**让暴力程序替你找规律 `[G]`**：T1 算式不对时打印「每一轮的账单明细」（LGR-307 `file` 每轮固定多 `n(n+1)/2`）；T2 卡 30 分时打印 `((OR|mex)^OR)`（LGR-307 `func` 每次只多一个 `2^b`）。写 15 行暴力 + 一行 `cout` 胜过两小时干瞪眼。

## 5. 终极保险五条铁律 `[G]`（防「该拿的分没拿到」）

1. **if-else 分段隔离护城河**：新代码绝不覆盖旧保底分；特殊性质分支用独立 `if` 提前 `return`。
2. **每题必测 1 组极小退化数据**（`N=1` 或 2 个点的链）：专治叶子底座 `e[root].size()==1`（Day10 C）。
3. **SPJ / 多解构造题不写 15 行计分检验器绝不准提交**：检查输出是 `1..n` 合法排列、自算代价与官方 `.out` 一致。
4. **取消 `freopen` 注释后必须重新编译并生成 `.out`**。
5. **终端挂 `-fsanitize=undefined,address` 跑一遍大样例**。

## 6. 考场环境 / 试机 / 交付配置 `[G]`

- NOI Linux 手册转译：文件夹与 `freopen` 铁律、数组空间估算（`sizeof` 而不是手数 0）、Linux 重名禁区、`diff` 替代 `fc`、段错误/死循环定位、`rand()` 可直接用、C++ 写对拍避免 Bash 语法。

- 本地简易评测机 `check.cpp`：用 `ret != 0` 判 RE/TLE、2 行算运行时间，改 3 行变满血 `duipai.cpp`。
- 专治 `main` 打成 `mian`：Tab + ↑ 键；专治 10⁷ 毒瘤读入：8 行快读快写；考场搏命：贪心 + 局部随机微扰、`clock()` 卡时。

- **桌面/工程实地诊断 `[G]`**：克隆顺序、考号文件夹名不加后缀、`gen.cpp` 里自定义 `rand(int l,int r)` 的重名风险。
