# 99 收件箱｜未分类新材料隔离区

> **这个目录必须保持为空（除本 README）**。它存在的唯一目的：让后来的人 / AI 有一个「先放这里」的地方，而不是随手把文件丢进根目录制造混乱。
> `python3 tools/verify_repo.py` 会检查：本目录除 `README.md` 外若还有文件 → **FAIL**，并提示你执行分类导入。这是故意设的硬闸门。

## 使用流程（不超过 3 步）

```bash
# 1. 把新材料放进本目录（或任意外部目录）
# 2. 先试运行：看分类、去重、隐私拦截结果，不写任何文件
python3 tools/ingest_materials.py --src 备考资料库/99_收件箱_待归档 --dry-run
# 3. 正式导入（自动移到 01~08 分类目录、去重、写 INGEST_LOG.jsonl、重建索引）
python3 tools/ingest_materials.py --src 备考资料库/99_收件箱_待归档
python3 tools/build_repo_state.py && python3 tools/verify_repo.py
```

## 规则

1. 文件名保留原名即可，导入脚本会自动规范为 `YYYY-MM-DD_<主题>.<ext>`。
2. 含真实姓名/学校/考号/账号/邮箱/邀请码/鉴权 URL/原始按键或剪贴板明文的文件会被**硬拦截**，不会被导入；脚本只报文件名与命中类型，不打印内容。
3. `.7z` / `.mkv` / `raw_keys*` / `clipboard*` / 未脱敏账号页 / 完整聊天 / OCR 原文一律拒绝；>5 MB 的原始归档容器请先在外部脱敏、拆分。
4. 按 SHA-256 去重：内容已存在的文件不会重复导入，重复运行是幂等的。
5. 导入后清空本目录，并在 `../../维护日志.md` 追加一行（日期 / 文件数 / 命令输出 / commit SHA）。

分类映射、命名规范与八类资料位置见 [../README.md](../README.md)；全局写入规则见 [../../仓库治理规范.md](../../仓库治理规范.md)。
