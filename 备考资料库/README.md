## 3. 写入规范（防混乱，AI 请逐条照做）

1. **新材料先入 `99_收件箱_待归档/`**，再用 `python3 tools/ingest_materials.py --src <目录>` 分类导入；不要直接往根目录扔文件。
2. **命名**：`YYYY-MM-DD_<主题>.<ext>`，主题用小写拼音/英文或简短中文，不含空格、括号、`(1)`、盘符、真实姓名/考号。
3. **每份新资料必须自带三行头**（Markdown 适用）：
   ```
   > 日期：YYYY-MM-DD｜等级：[OJ]/[F]/[R]/[V]/[U]/[G]/[E]/[X]
   > 来源：<文件路径 / record 号 / 用户提供材料名>
   > 状态：IDEA/PROVED/CODED/VERIFIED/FROZEN/SUBMITTED/SCORED/UNKNOWN
   ```
4. **禁止**：新文档自称「唯一入口 / 首读 / 最新 / 当前状态」；手写分数与总分；用 `[G]` 当结论；移动或覆盖历史快照；上传原始录屏/按键/剪贴板/完整聊天/账号页/OCR 原文与鉴权 URL/未脱敏源码历史；新增 >5 MB 原始归档容器。
5. **收件箱纪律**：`99_收件箱_待归档/` 除 `README.md` 外必须为空。`tools/verify_repo.py` 会把它当未分类混乱并判 FAIL —— 这是故意的。
6. **批量导入后必须**：`python3 tools/build_repo_state.py` → `python3 tools/verify_repo.py` → `../维护日志.md` 追加一行 → 提交并报告真实 SHA。
7. **知识点状态**：只改 `知识点掌握度.csv` 的状态列并追加证据列，不删历史行；状态必须有仓库内可点开的证据，否则保持 `UNKNOWN`。

## 4. 和 NOIP 控制层的关系

- `../NOIP2026/` = **计划与队列**（什么时候做什么、验收标准）。
- `备考资料库/` = **资料与能力现状**（有什么可学、每个知识点到哪一步）。
- `../总览/赛事账本.json` = **成绩与证据**（唯一分数事实源）。
- 三者互不覆盖；任何一处改动都要跑 `build_repo_state.py` 让索引同步。
