## 每级统一验收模板（照抄，不许口头宣布完成）

```
[证据] 官方 record / 保存快照 SHA / 命令输出 / 日期
[动作] 原思路 → 假说 → 最小反例 [X] → 最小 diff → 是否实际提交
[状态] IDEA/PROVED/CODED/VERIFIED/FROZEN/SUBMITTED/SCORED
[验证] 命令 + 种子 + 组数 + 真值来源 + 限制（LOCAL-VERIFIED ≠ OJ-AC）
[同步] 账本 JSON → build_repo_state.py → verify_repo.py → commit SHA + 回读
[剩余] 明确写出还不知道什么
```

> 边界：本路线是**训练计划**，不是成绩预测。`[G]` 的「一学换回 50~100 分」、目标 180~220、课程完成度都是外部 AI 的教学判断，未经本仓库复跑。
